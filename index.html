Bisa tempel langsung format JS const firebaseConfig = { ... }; atau JSON.

Langkah Setup Firebase Gratis (Sekali Seumur Hidup):

  1. Buka console.firebase.google.com → Create a project.
  2. Menu kiri: Build → Firestore Database → Create database → pilih Start in test mode.
  3. Klik ikon Gear (Project Settings) → scroll ke bawah → klik ikon Web (</>) → salin isi firebaseConfig ke kotak di atas.
  4. Klik Simpan & Hubungkan Cloud, lalu klik Salin Link untuk Tab / HP agar Tablet otomatis ikut tersambung!
